# โครงการแกล้งดิน

## คำถาม

โครงการแกล้งดินตามแนวพระราชดำริที่กรมชลประทานมีส่วนร่วมคืออะไร?

## คำตอบ

**พื้นที่:** จังหวัดนราธิวาส ภาคใต้ (พื้นที่ดินพรุ)

**ปัญหา:** ดินเปรี้ยวหรือดินพรุ ไม่เหมาะแก่การเพาะปลูก

**บทบาทกรมชลประทาน:** บริหารจัดการน้ำในพื้นที่โครงการ

**กระบวนการ "แกล้งดิน":**

```
1. ทำให้ดินแห้ง (แกล้งดิน)
   ↓ ออกซิเจนทำปฏิกิริยากับกรด
2. นำน้ำเข้าชะล้างความเป็นกรด
   ↓ ชะล้างสารกรดออก
3. สลับขั้นตอนซ้ำ
   ↓
4. ดินเปรี้ยว → ดินที่เหมาะสมแก่การเพาะปลูก
```

**ความสำคัญ:** เปลี่ยนพื้นที่ดินพรุที่ไม่มีประโยชน์ให้เป็นพื้นที่เกษตรกรรม

## ประเด็นสำคัญ

- ดินพรุ นราธิวาส
- ควบคุมระดับน้ำสลับแห้ง-ชะล้าง
- ชะล้างความเป็นกรดออก
- กรมชลประทานควบคุมน้ำ

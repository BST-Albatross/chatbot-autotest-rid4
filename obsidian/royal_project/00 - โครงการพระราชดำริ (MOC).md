## โครงการเฉพาะพื้นที่

| โครงการ | ที่ตั้ง | ประเด็นหลัก |
|---|---|---|
| [[ฝนหลวง]] | ทั่วประเทศ | ทำฝนเทียม แก้ภัยแล้ง |
| [[ลุ่มน้ำปากพนัง]] | นครศรีธรรมราช | แยกน้ำเค็ม-น้ำจืด |
| [[ห้วยฮ่องไคร้]] | เชียงใหม่ | ต้นแบบป่าต้นน้ำ |
| [[บึงมักกะสัน]] | กรุงเทพมหานคร | บำบัดน้ำเสีย แก้มลิง |
| [[ลุ่มน้ำก่ำ]] | สกลนคร-นครพนม | แก้น้ำท่วม |
| [[แกล้งดิน]] | นราธิวาส | แก้ดินเปรี้ยว |
| [[หนองใหญ่]] | ชลบุรี | แหล่งน้ำภาคตะวันออก |
| [[เขาหินซ้อน]] | ฉะเชิงเทรา | ศูนย์ศึกษาการพัฒนาแห่งแรก |
| [[โครงการพระราชดำริภาคเหนือตอนบน]] | ภาคเหนือ | พื้นที่สูง-ชาวเขา |
| [[แก้ปัญหาน้ำท่วมกรุงเทพ]] | กรุงเทพมหานคร | แก้มลิง-อุโมงค์ระบาย |

## หลักการและแนวคิด

- [[หลัก 3 น้ำ]] — น้ำดี น้ำเสีย น้ำท่วม
- [[เกษตรทฤษฎีใหม่]] — แบ่งพื้นที่ 4 ส่วน สระ 30%
- [[ฝายชะลอน้ำ]] — ชะลอน้ำ เพิ่มความชุ่มชื้น
- [[อนุรักษ์ต้นน้ำลำธาร]] — ปลูกป่า ฝาย ชุมชนมีส่วนร่วม

## หน่วยงาน

- [[กรมชลประทานกับโครงการพระราชดำริ]] — ออกแบบ ก่อสร้าง บริหารน้ำ
- [[สำนักงาน กปร.]] — ประสานงาน จัดสรรงบ ติดตามผล

# หลักการ 3 น้ำ

## คำถาม

หลักการ 3 น้ำ ในแนวพระราชดำริของรัชกาลที่ 9 คืออะไร?

## คำตอบ

หลักการ 3 น้ำ เป็นแนวคิดพื้นฐานในการบริหารจัดการน้ำของกรมชลประทาน

```
┌─────────────────────────────────────────────────────────┐
│                    หลักการ 3 น้ำ                        │
├──────────┬──────────────────────────────────────────────┤
│ น้ำดี   │ จัดหาและพัฒนาแหล่งน้ำคุณภาพดี               │
│          │ สำหรับอุปโภคบริโภคและการเกษตร               │
├──────────┼──────────────────────────────────────────────┤
│ น้ำเสีย │ บำบัดและจัดการน้ำเสีย                       │
│          │ ก่อนปล่อยลงแหล่งน้ำธรรมชาติ                │
├──────────┼──────────────────────────────────────────────┤
│ น้ำท่วม │ ป้องกันและบรรเทาอุทกภัย                     │
│          │ โดยใช้หลักการแก้มลิงและระบบระบายน้ำ         │
└──────────┴──────────────────────────────────────────────┘
```

## ประเด็นสำคัญ

- น้ำดี = จัดหาแหล่งน้ำคุณภาพดี
- น้ำเสีย = บำบัดก่อนปล่อยลงธรรมชาติ
- น้ำท่วม = ป้องกันด้วยแก้มลิง

# ความสำคัญของอ่างเก็บน้ำต่อชุมชนชนบท

## คำถาม

โครงการพระราชดำริประเภทอ่างเก็บน้ำมีความสำคัญต่อชุมชนชนบทอย่างไร?

## คำตอบ

อ่างเก็บน้ำในโครงการพระราชดำริมีความสำคัญต่อชุมชนชนบท 5 ด้าน:

| ด้าน | รายละเอียด |
|---|---|
| 1. น้ำต้นทุน | แหล่งน้ำสำหรับอุปโภคบริโภคและการเกษตร |
| 2. แก้ภัยแล้ง | บรรเทาปัญหาภัยแล้งในพื้นที่ห่างไกล |
| 3. เกษตรตลอดปี | สนับสนุนการทำเกษตรกรรมตลอดปี ลดพึ่งพาน้ำฝน |
| 4. สัตว์น้ำ | แหล่งเพาะเลี้ยงสัตว์น้ำ เพิ่มรายได้ชุมชน |
| 5. ลดอพยพ | ลดการอพยพของแรงงานออกจากชนบท |

กรมชลประทานรับผิดชอบบริหารจัดการอ่างเก็บน้ำในโครงการพระราชดำริ

## ประเด็นสำคัญ

- น้ำต้นทุน
- บรรเทาภัยแล้ง
- เกษตรตลอดปี
- เพาะเลี้ยงสัตว์น้ำ
- ลดการอพยพแรงงาน
